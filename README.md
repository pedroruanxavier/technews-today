## 📌 Sobre o Projeto

O **TechNews Today** é um portal de notícias de tecnologia responsivo, construído utilizando técnicas modernas de estilização CSS pura. O objetivo principal do desafio foi aplicar conceitos avançados de layout e design visual respeitando limites estritos de código (sem uso de frameworks, JavaScript ou alterações no arquivo HTML original).

---

## 🎨 Recursos Visuais e Efeitos

- **Glassmorphism:** Header estilizado com efeito de vidro fosco utilizando `backdrop-filter`.
- **Texto em Degradê:** Título principal estilizado com gradiente de cores.
- **Header Fixo:** Navegação superior fixada no topo com `position: sticky`.
- **CSS Grid:** Organização do layout principal (vídeo e newsletter lado a lado).
- **Design Responsivo:** Adaptação fluida para telas de dispositivos móveis via *Media Queries*.

---

## 📋 Checklist do Desafio

- [x] Efeito Glassmorphism no header (`backdrop-filter`)
- [x] Texto do título com gradiente de cores (`background-clip: text`)
- [x] Layout estruturado com **CSS Grid**
- [x] Fixação do cabeçalho com `position: sticky`
- [x] Responsividade para celular (`@media query`)
- [x] CSS otimizado em **no máximo 50 linhas**
- [x] 100% CSS puro (sem frameworks, JS ou modificações no HTML)
